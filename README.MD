Mercurius Pretty: End of the Century English Patch - Sega Dreamcast (MACHINE TRANSLATED)

**WARNING**

Works on only the 1.003 revision of the game.

Using the patch:

Put files in the directory of an original, untouched disc image. CHD images will not work. GDI and accompanying track files only.

Run "apply_xdelta.bat" (no arguments) on an untouched original disc image. Don’t apply it to a disc that already has an older patch, because xdelta will refuse. Choose from one of the translation options. These apply only to the name entry methods of the fairy/homunculus.

Tested in Flycast and Retroarch with the Flycast core.

NOTE: The patch may rename the "track03.bin" file to "track03.bin.new".  If this happens delete "track03.bin" and remove the ".new" extension from the new file so it is named "track03.bin".

As with any ongoing project: EXPECT BUGS. Patch will be updated as bugs are found.

TRANSLATION NOTES: Text 100% translated, about 10% flagged for review, full playthrough not yet confirmed."
